# Сайт Сергея Васильевича Никифорова
Статический проект на HTML, CSS и JavaScript.

- `index.html` — главная страница
- `style.css` — дизайн-система и адаптивная вёрстка
- `script.js` — меню, анимации, прокрутка и демонстрационная форма
- `privacy.html` — предварительный шаблон политики конфиденциальности
- `assets/` — портрет и исходный логотип

Для локального просмотра откройте `index.html` или запустите `python -m http.server 8000`.

Важно: форма пока демонстрационная и не отправляет данные на сервер. Интеграции Telegram/e-mail, аналитика, согласие/cookie, окончательная политика, sitemap и доменные метаданные — этап 4. Перед публикацией также замените временный текстовый знак «АН» на подготовленную веб-версию логотипа и проверьте юридические тексты.
